# 重定向命令

**学习目标**

-   能够使用重定向命令将终端显示内容重定向到文件

* * *

### 1\. 重定向命令的介绍

重定向也称为输出重定向，把在终端执行命令的结果保存到目标文件。

### 2\. 重定向命令的使用

### 3\. 小结

-   终端内容保存到文件使用重定向有两种方式: **\>** 和 **\>>**
-   **\>** 表示每次只写入最新的数据，原有数据不保留。
-   **\>>** 表示每次在原有数据的基础上进行追加，原有数据会保留。
