# 获取和设置元素内容

**学习目标**

-   能够知道获取和设置元素内容的操作

* * *

### 1\. html方法的使用

jquery中的html方法可以获取和设置标签的html内容

**示例代码:**

```js
<script>
    $(function(){

        var $div = $("#div1");
        //  获取标签的html内容
        var result = $div.html();
        alert(result);
        //  设置标签的html内容，之前的内容会清除
        $div.html("你好");
        //  追加html内容
        $div.append("你好");

    });

    hello

```

**说明:**

给指定标签追加html内容使用**append方法**

### 2\. 小结

-   获取和设置元素的内容使用: html方法
-   给指定元素追加html内容使用: append方法
