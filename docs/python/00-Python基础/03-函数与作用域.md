## 3. 定义、调用与返回值

### 3.1 最小函数

```python
def greet(name):
    """返回问候语。（这是 docstring）"""
    return f"Hello, {name}"


print(greet("mini-dify"))     # Hello, mini-dify
```

| 组成 | 说明 |
| --- | --- |
| `def` | 定义关键字，后面是函数名与括号 |
| `name` | 形参（parameter） |
| 冒号 + 缩进 | 函数体 |
| `"""..."""` | docstring，可用 `help(greet)` 或 `greet.__doc__` 读取 |
| `return` | 返回值；省略则返回 `None` |

### 3.2 没有 return 就返回 None

```python
def log(msg):
    print(msg)          # 只打印，不返回

result = log("hi")      # 打印 hi
print(result)           # None
```

> 这是「链式调用报 `NoneType has no attribute`」的根源：以为函数返回了对象，其实返回 `None`。

### 3.3 函数也是对象

```python
print(greet)            # <function greet at 0x...>
print(type(greet))      # <class 'function'>
```

函数可以被赋值、放进容器、当参数传、当返回值返回——这就是「一等公民」，§9 展开。

## 4. 参数传递：对象引用传值（首次教学）

### 4.1 一句话结论

> Python 传的是**对象的引用**（按值传递这个引用）。函数内**重新赋值**形参不影响外部；但对**可变对象原地修改**会影响外部。

### 4.2 不可变对象：函数内改不动外面

```python
def add_one(n):
    n = n + 1        # 重新绑定 n 到新对象
    return n

x = 10
print(add_one(x))    # 11
print(x)             # 10  ← 外部不变
```

`n = n + 1` 创建了新整数对象，`n` 只是改绑；`x` 仍指向原来的 `10`。

### 4.3 可变对象：原地修改会影响外面

```python
def append_item(items):
    items.append("new")     # 原地修改，不重新绑定

data = ["a"]
append_item(data)
print(data)                 # ['a', 'new']  ← 外部也变了
```

```python
def replace_list(items):
    items = ["brand new"]   # 重新绑定到新 list，外部不受影响

data = ["a"]
replace_list(data)
print(data)                 # ['a']
```

### 4.4 心智模型

```
调用 f(data)：
    data ──┐
           ├──▶ [list 对象]
    items ─┘        （形参拿到的是同一个对象的引用）

items.append(...)   →  改对象本身      → 外部可见
items = [...]       →  改 items 的指向 → 外部不可见
```

> 与 Java 的引用传递类似，与 C 的指针传值也类似。**不要**记成「Python 是引用传递」——那是错的，因为重新绑定不会影响调用方。

### 4.5 实践建议

- 函数**默认不要**修改传入的可变参数（除非函数名明确表达「原地修改」，如 `list.sort()`）；
- 需要返回新数据时，内部先 `copy()` 或构造新容器；
- 这条规则在阶段 6（ORM 实体修改）和阶段 8（请求体）会反复出现。

## 5. 参数的五种形态

### 5.1 位置参数与关键字参数

```python
def create_app(name, description, public):
    return {"name": name, "description": description, "public": public}

# 全部按位置
create_app("blog", "博客应用", True)

# 全部按关键字（顺序无关，可读性更好）
create_app(public=True, name="blog", description="博客应用")

# 混用：位置参数必须在关键字参数之前
create_app("blog", description="博客应用", public=True)
```

### 5.2 默认参数

```python
def create_app(name, description="", public=False):
    ...

create_app("chat")                      # 用默认值
create_app("chat", public=True)         # 跳过中间的默认参数
```

### 5.3 `*args`：收集多余位置参数为元组

```python
def total(*nums):
    print(nums, type(nums))     # (1, 2, 3) <class 'tuple'>
    return sum(nums)

print(total(1, 2, 3))           # 6
```

### 5.4 `**kwargs`：收集多余关键字参数为字典

```python
def build(**options):
    print(options)              # {'timeout': 5, 'retries': 2}
    return options

build(timeout=5, retries=2)
```

### 5.5 仅关键字参数 `*`（首次教学）

```python
def create_access_token(*, user_id, role):
    ...
```

`*` 之后的参数**只能用关键字传**：

```python
create_access_token(user_id="u1", role="admin")   # ✅
create_access_token("u1", "admin")                 # ❌ TypeError
```

为什么这么设计：

- 调用处一眼看出含义（`role="admin"` 比 `"admin"` 清晰）；
- 以后加参数不会悄悄改变位置语义；
- 本项目 `security.py` 就是这样写的——**安全相关函数强制具名传参，防止传错位**。

### 5.6 仅位置参数 `/`（了解）

```python
def f(a, /, b):
    ...
```

`/` 之前的参数只能用位置传（3.8+）。日常业务代码很少用，标准库较多。

### 5.7 参数顺序规则

```
def f(pos_only, /, normal, *args, kw_only, **kwargs):
        └─ 仅位置 ─┘  └─ 普通 ─┘  └─ 收集位置 ┘  └─ 仅关键字 ┘  └─ 收集关键字 ─┘
```

记忆：**位置 → 默认 → `*args` → 仅关键字 → `**kwargs`**。

### 5.8 调用时的星号展开

```python
args = (1, 2)
kwargs = {"a": 3}
def f(x, y, a=0): ...

f(*args, **kwargs)      # 等价于 f(1, 2, a=3)
```

## 6. 可变默认参数陷阱（必考）

### 6.1 错误写法

```python
def add_item(item, bucket=[]):      # ❌
    bucket.append(item)
    return bucket

print(add_item("a"))    # ['a']
print(add_item("b"))    # ['a', 'b']  ← 期望 ['b']，却被上一次污染
```

### 6.2 原因

默认值**在函数定义时求值一次**，之后每次调用都复用同一个对象：

```python
def f(bucket=[]):
    print(id(bucket))

f()   # 140...  同一个 id
f()   # 140...  一模一样
```

### 6.3 正确写法

```python
def add_item(item, bucket=None):     # ✅
    if bucket is None:
        bucket = []
    bucket.append(item)
    return bucket
```

> 同样的坑适用于 `{}`、`set()`、以及任何可变对象作默认值。
> 补充：`immutable` 默认值（`0`、`""`、`None`、元组）是安全的。

## 7. 返回值

### 7.1 多返回值 = 返回元组

```python
def parse_range(text):
    low, high = text.split("-")
    return int(low), int(high)          # 本质是 (low, high)

lo, hi = parse_range("1-10")            # 调用方解包
print(lo, hi)                           # 1 10
```

项目实例（`apps/api-py/app/security.py`）：

```python
def create_access_token(*, user_id: str, role: str) -> tuple[str, int]:
    """返回 (token, expires_in 秒)。载荷：sub / role / iat / exp。"""
    ...
    return jwt.encode(...), expires_in
```

调用方：

```python
token, expires_in = create_access_token(user_id="u1", role="admin")
```

> 多返回值本质是元组，调用方可以整体接收，也可以解包。这不是「真的返回两个值」。

### 7.2 提前返回（卫语句）

```python
def normalize_role(role):
    if not role:
        return "user"          # 早返回，减少嵌套
    if role not in {"user", "admin"}:
        return "user"
    return role
```

> 推荐用「卫语句 + 早返回」替代深层 `if` 嵌套，可读性显著更好。

## 8. 作用域：LEGB（首次教学）

### 8.1 四个层级

| 字母 | 含义 | 例子 |
| --- | --- | --- |
| **L**ocal | 当前函数内部 | 函数里的局部变量 |
| **E**nclosing | 外层嵌套函数 | 闭包捕获的变量 |
| **G**lobal | 模块（文件）级 | 文件顶层定义的变量 |
| **B**uiltin | 内置命名空间 | `print`、`len`、`ValueError` |

查找顺序：**L → E → G → B**，找到即停。

### 8.2 局部变量遮蔽

```python
x = "global"

def show():
    x = "local"
    print(x)

show()          # local
print(x)        # global
```

### 8.3 只读外层变量是可以的

```python
count = 0

def report():
    print(count)     # 读取 global，合法

report()             # 0
```

### 8.4 在函数里赋值 = 创建局部变量

```python
count = 0

def increase():
    count = count + 1     # ❌ UnboundLocalError
```

原因：函数体内一旦出现对 `count` 的**赋值**，Python 就把它视为局部变量；右侧读取时它还没被赋值。

正确写法一——`global`：

```python
count = 0

def increase():
    global count
    count += 1

increase()
print(count)      # 1
```

正确写法二（更推荐）——用返回值 / 容器 / 类：

```python
def increase(value):
    return value + 1

count = increase(count)
```

> **`global` 是坏味道**：它让函数依赖外部状态、难测试。项目代码里几乎不该出现（本项目 `security.py` 一个都没有）。

### 8.5 `nonlocal`：改外层函数的变量

```python
def make_counter():
    count = 0

    def increase():
        nonlocal count      # 声明改的是 E 层，不是新建局部变量
        count += 1
        return count

    return increase

counter = make_counter()
print(counter())    # 1
print(counter())    # 2
```

这里 `increase` 就是**闭包**：它捕获了 `make_counter` 的局部变量 `count`，即使 `make_counter` 已返回，`count` 依然存活。

> 完整的闭包与装饰器机制见 `01-Python进阶/03`，本篇只需建立「E 层 + `nonlocal`」的直觉。

### 8.6 一个经典陷阱：循环中的闭包延迟绑定

```python
funcs = [lambda: i for i in range(3)]
print([f() for f in funcs])     # [2, 2, 2]  ← 不是 [0, 1, 2]
```

原因：`lambda` 里的 `i` 在**调用时**才查找，那时循环已结束，`i` 都是 2。

修复：

```python
funcs = [lambda i=i: i for i in range(3)]    # 用默认参数在定义时捕获当前值
print([f() for f in funcs])                  # [0, 1, 2]
```

> 这个坑在 FastAPI 路由注册、事件回调注册中真实存在。阶段 1/03 会从闭包角度再讲一次原理。

## 9. 函数是一等公民

### 9.1 赋值与传递

```python
def double(x):
    return x * 2

def apply(fn, value):
    return fn(value)

print(apply(double, 21))     # 42

operations = {"double": double}
print(operations["double"](3))   # 6
```

> 用字典存函数是「注册表模式」的雏形——项目的工具注册表（`app/tools/registry.py`）就是这个思路。

### 9.2 lambda：匿名单表达式函数

```python
square = lambda x: x * x
print(square(5))             # 25
```

限制：**只能写一个表达式**，不能有语句、不能有 `return`。适合短小的「一次性」函数。

### 9.3 典型用法：排序 key

```python
apps = [
    {"name": "blog", "stars": 10},
    {"name": "chat", "stars": 30},
    {"name": "rag", "stars": 20},
]

by_stars = sorted(apps, key=lambda a: a["stars"], reverse=True)
print([a["name"] for a in by_stars])    # ['chat', 'rag', 'blog']
```

`key` 接收的是**每个元素的映射函数**，Python 用它算出排序依据。

### 9.4 内置高阶函数

```python
nums = [1, 2, 3, 4]

print(list(map(lambda x: x * 2, nums)))       # [2, 4, 6, 8]
print(list(filter(lambda x: x % 2 == 0, nums)))  # [2, 4]
```

> 实际项目更常用列表推导式（阶段 1/02），`map`/`filter` 了解即可。

## 10. 递归（简述）

```python
def factorial(n):
    if n <= 1:          # 基准情形，必须有
        return 1
    return n * factorial(n - 1)

print(factorial(5))     # 120
```

要点：

- 必须有**终止条件**，否则 `RecursionError`；
- CPython 默认递归深度约 1000（`sys.getrecursionlimit()`）；
- 深递归改用循环或显式栈。

> 图遍历（阶段 12 引擎）会用递归/栈，但那时会有明确深度控制。

## 11. 项目实战：逐行读懂 security.py

完整文件路径：`apps/api-py/app/security.py`

```python
import bcrypt
import jwt

from app.config import settings

BCRYPT_ROUNDS = 10
JWT_ALGORITHM = "HS256"


def hash_password(password: str) -> str:
    return bcrypt.hashpw(
        password.encode("utf-8"),
        bcrypt.gensalt(rounds=BCRYPT_ROUNDS),
    ).decode("utf-8")


def verify_password(password: str, password_hash: str) -> bool:
    try:
        return bcrypt.checkpw(
            password.encode("utf-8"),
            password_hash.encode("utf-8"),
        )
    except ValueError:
        return False


def create_access_token(*, user_id: str, role: str) -> tuple[str, int]:
    """返回 (token, expires_in 秒)。载荷：sub / role / iat / exp。"""
    expires_in = settings.access_token_expires_in
    now = datetime.now(timezone.utc)
    payload = {
        "sub": user_id,
        "role": role,
        "iat": int(now.timestamp()),
        "exp": int((now + timedelta(seconds=expires_in)).timestamp()),
    }
    return jwt.encode(payload, settings.jwt_secret, algorithm=JWT_ALGORITHM), expires_in
```

用本篇知识逐条拆解：

| 代码 | 知识点 |
| --- | --- |
| `BCRYPT_ROUNDS = 10` | 模块级常量（G 层），函数内可直接**读取** |
| `def hash_password(password: str) -> str:` | 类型注解：参数 `str`、返回 `str`（运行时不强制，靠工具检查） |
| `password.encode("utf-8")` | `str` → `bytes` 转换（bcrypt 只吃字节） |
| `try/except ValueError: return False` | 异常兜底（阶段 0/05 详讲），让校验失败返回 `False` 而不是崩 |
| `def create_access_token(*, user_id, role)` | **仅关键字参数**：安全敏感函数强制具名传参 |
| `-> tuple[str, int]` | 返回元组类型注解 |
| `settings.access_token_expires_in` | 读模块级单例（G 层变量），没有 `global`，只读不写 |
| `return jwt.encode(...), expires_in` | 多返回值（元组），调用方解包 |
| 无 `global` | 函数纯粹依赖入参与配置，**可测试性好** |

> 值得注意的设计：`create_access_token` 不去写全局 `current_token` 之类的状态，而是**返回**结果。这是「函数式、无副作用」的写法，也是本项目双栈（TS/Python）行为一致性容易验证的原因之一。

## 12. 与 TypeScript 对照

| Python | TypeScript | 说明 |
| --- | --- | --- |
| `def f(a, b=1)` | `function f(a, b = 1)` | 默认值写法接近 |
| `*args` | `...args` | 都是收集为数组/元组 |
| `**kwargs` | 无直接等价（用 options 对象） | TS 通常 `f(opts: {a?: number})` |
| `*, user_id, role` | 无直接等价 | TS 靠解构 `{userId, role}` 强制具名 |
| `-> str` | `: string` | 类型注解位置不同 |
| `def` 内定义 `def` | 闭包/箭头函数 | 都支持嵌套函数 |
| `global x` | 无（模块作用域可变） | Python 需显式声明 |
| 默认参数在定义时求值 | 每次调用求值 | **行为不同**，Python 有可变默认陷阱 |

## 13. 验收自测

### 13.1 预测输出

```python
def f(a, bucket=[]):
    bucket.append(a)
    return bucket

print(f(1))
print(f(2))
```

<details>
<summary>答案</summary>

```
[1]
[1, 2]
```
因为默认值 `[]` 只创建一次，两次调用共享。

</details>

### 13.2 预测输出

```python
x = 1

def outer():
    x = 2
    def inner():
        nonlocal x
        x += 10
        return x
    return inner()

print(outer(), x)
```

<details>
<summary>答案</summary>

```
12 1
```
`nonlocal` 改的是 `outer` 的 `x`（2 → 12），全局 `x` 不受影响。

</details>

### 13.3 动手题

写一个函数 `pick_top(items, n=3, *, key=None)`：

- `items` 是列表；
- 返回前 `n` 个元素（按 `key` 排序，`key` 为 `None` 时保持原顺序）；
- 不允许修改原列表。

参考实现：

```python
def pick_top(items, n=3, *, key=None):
    ordered = sorted(items, key=key) if key else list(items)
    return ordered[:n]
```

## 14. 常见坑

| 现象 | 原因 | 解决 |
| --- | --- | --- |
| 两次调用结果「串味」 | 可变默认参数只创建一次 | 默认写 `None`，函数内初始化 |
| `UnboundLocalError: local variable referenced before assignment` | 函数内赋值把名字变成局部 | 用返回值；确需修改用 `global`/`nonlocal` |
| 函数里 `append` 后外部列表也变了 | 传的是同一对象引用 | 需要独立性就先 `copy()` |
| 函数返回 `None`，链式调用报错 | 忘了 `return` | 检查每个分支都有返回 |
| `[lambda: i for i in ...]` 全是最后一个值 | 闭包延迟绑定 | `lambda i=i: i` 捕获当前值 |
| `sorted(x, key=lambda a: a["x"])` 报 `KeyError` | 元素缺键 | 用 `a.get("x", 0)` 或先清洗数据 |
| 参数顺序写错：`def f(a=1, b)` | 默认参数后不能跟无默认的位置参数 | 调整顺序或改用仅关键字 |
| `f(*args)` 传了 dict 却报错 | `*` 展开的是键 | 字典用 `f(**kwargs)` |
| 位置传参给了仅关键字函数 | 签名有 `*` | 全部用 `参数名=值` 调用 |
| 递归爆栈 | 无终止条件或深度过大 | 加基准情形；改循环 |

## 15. 本篇小结

- **`def` + `return`**：省略 `return` 即返回 `None`；多返回值本质是元组。
- **参数传递是对象引用传值**：重新绑定不影响调用方，原地修改会影响；默认不修改传入的可变对象。
- **参数五形态**：位置 → 默认 → `*args` → 仅关键字（`*`）→ `**kwargs`；`*` 强制具名，适合安全敏感函数。
- **可变默认参数只创建一次**：一律用 `None` 占位再初始化。
- **LEGB**：局部 → 外层 → 全局 → 内置；函数内赋值即声明局部，改外层需 `global`/`nonlocal`，但**优先用返回值替代**。
- **函数是一等公民**：可传可返回，`lambda` + `sorted(key=...)` 是最高频用法；循环里创建闭包要防延迟绑定。
- **无副作用优先**：本项目 `security.py` 全部是「入参 → 返回值」，不写全局状态，这是可测试性的基础。
- **下一步**：模块、包与导入——把函数组织成可复用的包。
