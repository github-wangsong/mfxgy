## 3. 变量：名字是标签，不是盒子

### 3.1 赋值到底发生了什么

```python
x = 42
```

很多人把 `x` 想成一个装 42 的盒子。Python 的真实模型是：

```
   内存对象 42（一个 int 对象，有 id、type、value）
        ▲
        │ 指向
      x（名字，绑定在某个命名空间里）
```

验证：

```python
x = 42
print(id(x), type(x), x)
```

输出示例：

```
140703315980048 <class 'int'> 42
```

`id()` 返回对象标识（CPython 中通常是内存地址）。**变量本身没有类型，对象才有类型**。

### 3.2 重新赋值 = 改绑，不是改对象

```python
a = [1, 2, 3]
b = a          # b 与 a 指向同一个 list 对象
b.append(4)
print(a)       # [1, 2, 3, 4]  ← a 也变了
```

```python
a = [1, 2, 3]
b = a.copy()   # 复制出一个新 list
b.append(4)
print(a)       # [1, 2, 3]     ← a 不受影响
```

> 这是 Python 最容易出 bug 的地方之一，下一篇讲参数传递时会再次遇到（默认参数陷阱）。

### 3.3 命名规范（PEP 8）

| 对象 | 风格 | 示例 |
| --- | --- | --- |
| 变量/函数 | `snake_case` | `database_url`、`search_chunks` |
| 类 | `PascalCase` | `Settings`、`KnowledgeBase` |
| 常量 | `UPPER_SNAKE` | `_PROJECT_DIR`、`MAX_ROUNDS` |
| 私有（约定） | 前导下划线 | `_PROJECT_DIR`、`_internal` |

> Python 没有真正的 `private`。单下划线是**约定**（别外部用），双下划线会触发名称改写（name mangling），阶段 0/06 面向对象再讲。

## 4. 缩进就是语法块

Python 用**缩进**表示代码块，不用 `{}`。这是它和 TS/Java 最大的外观差异，也是新手第一个报错来源。

```python
score = 85

if score >= 60:
    print("及格")
    if score >= 90:
        print("优秀")
else:
    print("不及格")
```

规则：

| 规则 | 说明 |
| --- | --- |
| 冒号 `:` 开启代码块 | `if`/`for`/`while`/`def`/`class`/`try` 都以 `:` 结尾 |
| 同一块缩进必须一致 | 惯例 **4 个空格**，不要混 Tab |
| 空块用 `pass` | 占位，语法要求必须有语句 |
| 块结束靠「减少缩进」 | 没有 `end` 关键字 |

```python
def todo():
    pass   # 先占位，避免 IndentationError / SyntaxError
```

> 缩进错误会直接抛 `IndentationError`，属于**语法错误**，代码根本没开始跑。

## 5. 数字类型

### 5.1 int：没有上限

```python
big = 2 ** 200
print(big)          # 1606938044258990275541962092341162602522202993782792835301376
print(type(big))    # <class 'int'>
```

与 C/Java 的 `int` 溢出不同，**Python 整数自动扩展精度**（代价是大数运算变慢）。

### 5.2 float：二进制小数，天然有误差

```python
print(0.1 + 0.2)            # 0.30000000000000004
print(0.1 + 0.2 == 0.3)     # False
```

原因：`0.1` 在二进制里是无限循环小数，存进 64 位浮点必然被截断。

正确做法：

```python
import math

print(math.isclose(0.1 + 0.2, 0.3))        # True
print(abs((0.1 + 0.2) - 0.3) < 1e-9)       # True
```

> **涉及金额/精确计算**时不要用 `float`：用 `decimal.Decimal`，或直接以「分」为单位存整数。

### 5.3 除法有两个

```python
print(7 / 2)    # 3.5   真除法，结果总是 float
print(7 // 2)   # 3     向下取整（floor）
print(-7 // 2)  # -4    注意：向下取整不是向零取整
print(7 % 2)    # 1     取余
print(2 ** 10)  # 1024  幂
```

> `-7 // 2 == -4` 是高频坑：Python 的 `//` 是「地板除」，而 C/Java/JS 的整数除法向零截断。

### 5.4 bool 是 int 的子类

```python
print(True + True)      # 2
print(isinstance(True, int))   # True
```

布尔值 `True`/`False` 本质是 `1`/`0`，可以和数字混算（但别滥用，影响可读性）。

### 5.5 数字的可读性写法

```python
population = 1_400_000_000     # 下划线只是分隔，运行时被忽略
print(population)              # 1400000000
```

## 6. 字符串

### 6.1 四种写法

```python
s1 = 'single'
s2 = "double"
s3 = """多行
字符串"""
s4 = r"C:\Users\name"          # r 前缀：原始字符串，反斜杠不转义
```

| 写法 | 场景 |
| --- | --- |
| `'...'` / `"..."` | 等价，选一种避免内部转义 |
| `'''...'''` / `"""..."""` | 多行文本、文档字符串 docstring |
| `r"..."` | 正则、Windows 路径 |
| `f"..."` | **格式化，最常用** |

### 6.2 f-string（首次教学）

```python
name = "mini-dify"
port = 8000
print(f"{name} 监听 {port}")
print(f"{name.upper()} 监听 {port:05d}")
print(f"耗时 {0.87654:.2f}s")
```

输出：

```
mini-dify 监听 8000
MINI-DIFY 监听 08000
耗时 0.88s
```

格式说明符速查：

| 写法 | 含义 |
| --- | --- |
| `{x:05d}` | 整数补零到 5 位 |
| `{x:.2f}` | 保留 2 位小数 |
| `{x:>10}` / `{x:<10}` / `{x:^10}` | 右/左/居中对齐，宽度 10 |
| `{x:,}` | 千分位分隔 |
| `{x!r}` | 用 `repr()` 显示（调试常用） |

> `f"{x!r}"` 在调试时很有用：字符串会带引号，`None` 会显示 `None`，一眼看出类型。

### 6.3 常用方法

```python
s = "  Mini-Dify Backend  "
print(s.strip())                 # 'Mini-Dify Backend'
print(s.strip().lower())         # 'mini-dify backend'
print("a,b,c".split(","))        # ['a', 'b', 'c']
print("-".join(["a", "b"]))      # 'a-b'
print("abc".startswith("ab"))    # True
print("abc".replace("b", "B"))   # 'aBc'
print("hello".find("ll"))        # 2
```

### 6.4 字符串不可变

```python
s = "abc"
# s[0] = "A"        # TypeError: 'str' object does not support item assignment
s = "A" + s[1:]     # 只能造一个新字符串
print(s)            # 'Abc'
```

> 所有「看起来在改字符串」的方法（`replace`/`upper`/`strip`）都**返回新字符串**，原串不变。忘记接收返回值是最常见的 bug。

## 7. None 与真值规则（首次教学）

### 7.1 None 表示「没有值」

```python
result = None
if result is None:
    print("还没有结果")
```

> **判断 `None` 永远用 `is None`**，不要用 `== None`（虽然能跑，但语义不对，且可能被子类 `__eq__` 干扰）。

### 7.2 falsy 全表

以下值在 `if`/`while`/`and`/`or` 中会被当作 `False`：

| 类型 | falsy 值 |
| --- | --- |
| `bool` | `False` |
| `None` | `None` |
| 数字 | `0`、`0.0`、`0j` |
| 字符串 | `""` |
| 容器 | `[]`、`()`、`{}`、`set()` |
| 其他 | 定义了 `__bool__` 返回 False 或 `__len__` 返回 0 的对象 |

其余都为真，包括 `"0"`、`[0]`、`-1`。

```python
items = []
if not items:
    print("空列表")     # 会打印

if items:               # 比 len(items) > 0 更 Pythonic
    print("非空")
```

### 7.3 短路求值与默认值

```python
name = ""
display = name or "匿名用户"
print(display)          # 匿名用户

config = {"port": 0}
port = config.get("port") or 8000
print(port)             # 8000  ← 注意：0 也是 falsy，被替换掉了！
```

> 上面这条是**真坑**：用 `or` 给默认值会把合法的 `0`/`""`/`[]` 当成「没填」。需要区分「键不存在」时用 `in` 或 `get(key, default)`：

```python
port = config["port"] if "port" in config else 8000   # 0 会被保留
```

## 8. 四大容器

### 8.1 list：有序、可变、可重复

```python
apps = ["blog", "chat", "rag"]

print(apps[0])        # blog（索引从 0 开始）
print(apps[-1])       # rag（负数从末尾数）
print(len(apps))      # 3

apps.append("agent")          # 尾部加一个
apps.extend(["a", "b"])       # 尾部加多个
apps.insert(0, "first")       # 指定位置插入
apps.remove("chat")           # 按值删（不存在会 ValueError）
last = apps.pop()             # 弹出尾部
print(apps)
```

输出：

```
['first', 'blog', 'rag', 'agent', 'a']
```

排序：

```python
nums = [3, 1, 2]
nums.sort()                 # 原地排序，返回 None
print(nums)                 # [1, 2, 3]

sorted_nums = sorted(nums, reverse=True)   # 返回新列表
print(sorted_nums)          # [3, 2, 1]
```

> `sort()` 原地改、返回 `None`；`sorted()` 返回新列表。把 `nums = nums.sort()` 写成一行会得到 `None`——高频错误。

### 8.2 tuple：有序、不可变

```python
point = (3, 4)
x, y = point           # 解包
print(x, y)            # 3 4

single = (1,)          # 单元素元组必须有逗号
print(type(single))    # <class 'tuple'>
print(type((1)))       # <class 'int'>  ← 没有逗号就是普通括号
```

用途：函数返回多个值（本质是元组）、作为 `dict` 的键、表达「不该被改」的数据。

### 8.3 dict：键值映射、插入有序（3.7+）

```python
settings = {
    "service_name": "api-py",
    "port": 8000,
}

print(settings["port"])              # 8000（键不存在会 KeyError）
print(settings.get("missing"))       # None
print(settings.get("missing", 0))    # 0

settings["version"] = "0.1.0"        # 新增/覆盖
del settings["version"]              # 删除

for key, value in settings.items():
    print(key, value)

print(list(settings.keys()))         # 键列表
print("port" in settings)            # True（判断键，不是值）
```

合并：

```python
a = {"x": 1}
b = {"y": 2}
print(a | b)                 # {'x': 1, 'y': 2}  （3.9+）
a.update(b)                  # 原地合并
```

> **键必须可哈希**（不可变）：`str`/`int`/`tuple` 可以，`list`/`dict` 不行。这是 `tuple` 存在的重要理由之一。

### 8.4 set：无序、去重、集合运算

```python
tags = {"rag", "agent", "rag"}
print(tags)                  # {'rag', 'agent'}  ← 自动去重

empty = set()                # 注意：{} 是空 dict，不是空 set！

a = {1, 2, 3}
b = {2, 3, 4}
print(a & b)                 # {2, 3}      交集
print(a | b)                 # {1, 2, 3, 4} 并集
print(a - b)                 # {1}          差集
print(a ^ b)                 # {1, 4}       对称差
```

判断成员：`x in set` 平均 O(1)，比 `x in list` 的 O(n) 快得多。

### 8.5 选型表

| 需求 | 选择 |
| --- | --- |
| 有序、要增删 | `list` |
| 有序、不改（当键/返回多值） | `tuple` |
| 按键查找 | `dict` |
| 去重、集合运算、快速判存在 | `set` |

### 8.6 可变 vs 不可变

| 不可变 | 可变 |
| --- | --- |
| `int`、`float`、`bool`、`str`、`tuple`、`frozenset` | `list`、`dict`、`set`、自定义类实例 |

含义：

- 不可变对象可作为 `dict` 键、`set` 元素；
- 可变对象做默认参数会「跨调用共享」（阶段 0/03 详讲）；
- 函数收到可变对象时，**原地修改会影响调用方**。

## 9. 切片（首次教学）

语法：`序列[start:stop:step]`

| 部分 | 含义 | 省略时 |
| --- | --- | --- |
| `start` | 起始索引（含） | 从头 |
| `stop` | 结束索引（**不含**） | 到尾 |
| `step` | 步长（可为负） | 1 |

```python
s = "abcdefg"

print(s[1:4])      # bcd      索引 1,2,3
print(s[:3])       # abc
print(s[3:])       # defg
print(s[-2:])      # fg       最后两个
print(s[::2])      # aceg     隔一个取一个
print(s[::-1])     # gfedcba  反转
print(s[-3::2])    # eg       倒数第三个开始，步长 2
```

作用范围：`str`、`list`、`tuple`、`bytes`，以及支持 `__getitem__` 的对象。

> 切片**永远不会越界报错**：`s[100:]` 返回 `""`。但单索引会：`s[100]` 抛 `IndexError`。

列表切片返回**新列表**（浅拷贝）：

```python
a = [1, 2, 3]
b = a[:]
b.append(4)
print(a, b)        # [1, 2, 3] [1, 2, 3, 4]
```

## 10. 比较与运算

### 10.1 `==` 与 `is`（高频考点）

| 运算符 | 比较什么 | 用途 |
| --- | --- | --- |
| `==` | **值**是否相等（调用 `__eq__`） | 业务判断 |
| `is` | 是否是**同一个对象**（`id` 相同） | 只用于 `None`/`True`/`False`/哨兵对象 |

```python
a = [1, 2, 3]
b = [1, 2, 3]
print(a == b)     # True
print(a is b)     # False（两个不同对象）
```

```python
x = None
print(x is None)  # True   ← 正确写法
print(x == None)  # True   ← 能跑，但不推荐
```

> 小整数（-5~256）和短字符串会被 CPython 缓存，`is` 偶尔「碰巧」为 True，**绝不能依赖**。

### 10.2 链式比较与逻辑运算

```python
age = 25
print(18 <= age < 60)        # True，等价于 18 <= age and age < 60

print(True and "x")          # x   （and 返回第一个 falsy 或最后一个值）
print(False and "x")         # False
print(None or "default")     # default
print("" or 0 or "last")     # last
```

> `and`/`or` 返回的是**操作数本身**，不是 `True`/`False`。这是 `x or default` 写法的原理。

### 10.3 三元表达式

```python
status = "ok" if score >= 60 else "fail"
```

顺序是 `值 if 条件 else 值`，与 TS 的 `cond ? a : b` 对应。

## 11. 解包与星号（首次教学）

```python
# 1. 多变量赋值
a, b = 1, 2

# 2. 交换（不需要临时变量）
a, b = b, a

# 3. 元组/列表解包
x, y = (3, 4)

# 4. 星号收集剩余
first, *rest = [1, 2, 3, 4]
print(first, rest)        # 1 [2, 3, 4]

head, *middle, tail = [1, 2, 3, 4, 5]
print(middle)             # [2, 3, 4]

# 5. 调用时展开
nums = [1, 2, 3]
print(*nums)              # 1 2 3  （等价于 print(1, 2, 3)）
```

> 函数定义里的 `*args`/`**kwargs` 是同一套星号机制的另一面，下一篇讲。

## 12. 类型转换

```python
int("42")          # 42
int("42", 10)      # 42（指定进制）
int(3.9)           # 3   截断，不四舍五入
float("3.14")      # 3.14
str(42)            # '42'
bool(0)            # False
bool("0")          # True ← 非空字符串都是 True
list("abc")        # ['a', 'b', 'c']
list({"a": 1})     # ['a']  对 dict 转 list 得到键列表
tuple([1, 2])      # (1, 2)
set([1, 1, 2])     # {1, 2}
dict([("a", 1)])   # {'a': 1}
```

转换失败抛 `ValueError`：

```python
int("abc")   # ValueError: invalid literal for int() with base 10: 'abc'
```

> 这就是阶段 0/05「异常处理」要解决的问题：用户输入永远不可信。

## 13. 项目实战：读懂 config.py 里的类型

完整文件路径：`apps/api-py/app/config.py`（节选）

```python
from pathlib import Path

_PROJECT_DIR = Path(__file__).resolve().parent.parent

class Settings(BaseSettings):
    service_name: str = "api-py"
    version: str = "0.1.0"
    database_url: str = "postgresql+psycopg://postgres:difyai123456@localhost:5432/minidify"
    jwt_secret: str = "dev-jwt-secret-change-me-please"
    access_token_expires_in: int = Field(default=3600, validation_alias="JWT_EXPIRES_IN")
    port: int = 8000
    llm_base_url: str = "https://api.openai.com/v1"
    llm_api_key: str = ""
    llm_model: str = "gpt-4o-mini"
    llm_timeout_ms: int = 60000
    max_tool_rounds: int = 5
    embedding_model: str = "text-embedding-3-small"

settings = Settings()
```

用本篇知识逐条解释：

| 代码 | 用到的知识点 |
| --- | --- |
| `Path(__file__).resolve().parent.parent` | `__file__` 是当前文件路径字符串；`Path` 是标准库路径对象；`.parent` 属性、链式调用 |
| `service_name: str = "api-py"` | 变量 + **类型注解**（此处由 Pydantic 在运行时校验，注解不是装饰） |
| `llm_api_key: str = ""` | 空字符串是 falsy，表示「未配置」——这就是为什么后面要用 `if not settings.llm_api_key` 判断 |
| `port: int = 8000` | 整数默认值；环境变量读进来是字符串，由 Pydantic 转 `int` |
| `llm_timeout_ms: int = 60000` | 下划线数字写法的等价形式（这里没用下划线，但 `60_000` 也可以） |
| `settings = Settings()` | 模块级单例：**模块只被导入一次**，所以全项目共享同一个 `settings` 对象 |

> 注意 `_PROJECT_DIR` 前导下划线：约定为模块私有，外部不要 `from app.config import _PROJECT_DIR`。

## 14. 与 TypeScript 对照

| Python | TypeScript | 差异要点 |
| --- | --- | --- |
| `x = 42`（无声明） | `const x = 42` | Python 无 `const`/`let`，重新赋值随时可以 |
| `int`（无上限） | `number`（IEEE754 双精度） | Python 大整数精确；JS 超过 2^53 丢精度 |
| `float` | `number` | 都不精确，比较都要容差 |
| `str` | `string` | 都不可变 |
| `list` | `Array` | 方法名不同（`append` vs `push`） |
| `tuple` | `readonly [A, B]` | Python 元组运行期真不可变 |
| `dict` | `Record<K, V>` / `Map` | Python `dict` 保插入序；JS 对象键会转字符串 |
| `set` | `Set` | 用法接近 |
| `None` | `null` / `undefined` | Python 只有一个空值 `None` |
| `is None` | `=== null` | Python 用 `is` 判身份 |
| f-string | 模板字符串 `` `${x}` `` | 功能接近，Python 多了格式说明符 |

## 16. 常见坑

| 现象 | 原因 | 解决 |
| --- | --- | --- |
| `IndentationError` | 缩进不一致、混用 Tab 与空格 | 统一 4 空格；编辑器开「显示空白字符」 |
| `b = a` 后改 `b`，`a` 也变了 | 两者指向同一可变对象 | 需要独立副本时用 `a.copy()` / `a[:]` / `copy.deepcopy` |
| `0.1 + 0.2 == 0.3` 为假 | 浮点二进制精度 | `math.isclose`；金额用 `Decimal` 或整数分 |
| `nums = nums.sort()` 后 `nums` 是 `None` | `sort()` 原地排序返回 `None` | 用 `sorted(nums)` 或分两行写 |
| `-7 // 2` 得到 `-4` 而非 `-3` | `//` 是地板除 | 需要向零取整用 `int(a / b)` 或 `math.trunc` |
| `s[0] = "A"` 报错 | 字符串不可变 | 拼接/切片造新串，或用 `list(s)` 改后再 `"".join` |
| `{}` 被当成空集合 | `{}` 是空 `dict` | 空集合写 `set()` |
| `x == None` 判断失败 | 某些对象重载了 `__eq__` | 一律 `is None` |
| `d["k"]` 抛 `KeyError` | 键不存在 | `d.get("k", default)` 或 `"k" in d` |
| `config.get("port") or 8000` 得到 8000 | `0` 是 falsy | 用 `"port" in config` 判断是否存在 |
| 循环里字符串 `+=` 很慢 | 每次拼接都造新对象 | 收集到 list 后 `"-".join(...)` |

## 17. 本篇小结

- **变量是标签**：`a = b` 让两个名字指向同一对象；改可变对象会互相影响。
- **缩进即语法**：4 空格、冒号开块、空块用 `pass`。
- **数字**：`int` 无上限；`float` 有精度误差，比较用 `math.isclose`；`//` 是地板除。
- **字符串不可变**：所有「修改」方法都返回新串；f-string 是唯一推荐的格式化方式。
- **真值规则**：`0`/`""`/`[]`/`{}`/`None` 都是 falsy，所以 `x or default` 会吞掉合法的 `0`。
- **容器四件套**：`list` 有序可变、`tuple` 有序不可变（可作键）、`dict` 按键查、`set` 去重与集合运算。
- **切片**：`[start:stop:step]`，`stop` 不含，支持负数与反转，越界不报错。
- **`==` 比值，`is` 比身份**；判空一律 `is None`。
- **下一步**：函数与作用域——参数传递、默认参数陷阱、`*args/**kwargs`、LEGB。
