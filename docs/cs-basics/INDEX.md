## 四、面试答题模板

1. **先给结论**：一句话回答「是什么 / 为什么」。
2. **再讲机制**：分 2~3 步讲清关键流程。
3. **最后落到项目**：补一句「我在项目里怎么用 / 怎么排查」。
4. **不会时**：说清边界「这块我只做过 X，Y 还需要确认」，不要硬编。

## 六、使用建议

- **先骨架后细节**：每篇先看「一张图」，能复述再往下看。
- **每题先说人话**：面试官更在意你的推理过程，不是背定义。
- **结合项目**：每个知识点至少准备一个「我在 Agent 项目里怎么用」的例子。
- **不要死背数字**：延迟数字记数量级即可，现场能说「内存约 100ns、SSD 约 100µs、跨地域网络约几十 ms」就够。
