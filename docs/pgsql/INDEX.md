## 系列特色

- **MySQL 对照**：全程标注 PG 与 MySQL 的行为差异，有 MySQL 经验可快速建立心智模型。
- **教学式命令**：每条 SQL 带目的说明与完整可运行代码，首次出现的技术点配套语法教学。
- **项目落地**：以 mini-dify 数据层（jsonb 画布两态、pgvector 知识库、Prisma+SQLAlchemy 双栈）为真实样本。
- **验收自测**：每篇附验收自测与常见坑，学完即可用 [学习总结](./学习总结.md) 的自测清单检验。
